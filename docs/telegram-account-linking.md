# Привязка Telegram к существующему email-аккаунту

В кабинете https://lk.du2.ru/settings/telegram пользователь создаёт одноразовую ссылку. Telegram отправляет `/start link_<token>` в существующий n8n Telegram Trigger workflow 124. n8n передаёт update в защищённый Laravel API, получает текст подтверждения и отправляет его Telegram-ботом.

Токен действителен 10 минут и используется один раз. Привязка не меняет исходный users.id; если Telegram раньше автоматически создал отдельный аккаунт, его привычки и отметки переносятся в email-аккаунт. Привязка Telegram, принадлежащего обычному чужому аккаунту, блокируется.

Laravel не регистрирует Telegram webhook. Для напоминаний пользователь может отправить `/du2start`, для отключения — `/du2stop`. Прочие сообщения и callback не затрагиваются.
