# Привязка Telegram к существующему email-аккаунту

1. Войти на lk.du2.ru по email и открыть дашборд.
2. Нажать «Привязать Telegram», затем «Получить ссылку».
3. Открыть одноразовую ссылку и подтвердить /start в личном чате @softskillsimprovement_bot.
4. Обновить страницу и увидеть статус привязки. Привычки остаются в исходном users.id.

Токен случаен, хранится только SHA-256, действует 10 минут, одноразовый. При создании нового старые неиспользованные токены удаляются. Если Telegram уже создал отдельную автоматическую учётную запись (email вида telegram-<id>@users.lk.du2.invalid), она объединяется с email-аккаунтом: все привычки и отметки переносятся в существующий email-аккаунт. Обычный чужой аккаунт Telegram перепривязать нельзя. Webhook защищён секретом бота.

Миграция: `telegram_link_tokens`. После обновления GitHub: `bash ~/du2-app/deploy.sh`.
