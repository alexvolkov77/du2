# DU2 0.4 — Telegram-напоминания и быстрые отметки

Бот: [@softskillsimprovement_bot](https://t.me/softskillsimprovement_bot)

Реализовано:
- В привычке можно включить или выключить напоминание и выбрать время (формат HH:mm).
- Напоминание отправляется только в запланированный день, по сохранённому часовому поясу пользователя, если нет отметки выполнения.
- По умолчанию напоминания отключены.
- Telegram-сообщение содержит кнопку «✅ Выполнено», которая отмечает привычку в MySQL без открытия Mini App.
- Повторные отправки за один день предотвращаются атомарным обновлением last_reminded_on.
- Кнопка подписана HMAC, принимается только для владельца связанного Telegram-чата и только в день отправки.
- Команды /start и /stop подключают и отключают доставку напоминаний в личный чат.
- Обработка Telegram обновлений защищена секретным заголовком Telegram Bot API.

## Развёртывание

В существующем `.env` должен быть `TELEGRAM_BOT_TOKEN`.

```bash
bash ~/du2-app/deploy.sh
```

Deploy обновляет сайт, выполняет миграцию, регистрирует Telegram webhook
`https://lk.du2.ru/telegram/webhook` и устанавливает cron раз в минуту
для `php artisan schedule:run`.

Если у бота уже есть webhook с другим URL, установка остановится без перезаписи.
Владелец должен проверить, кто использует этот webhook, и только затем
выполнить `php artisan telegram:configure-webhook --force`.

## Приёмка

1. Открой [бота](https://t.me/softskillsimprovement_bot), отправь `/start`.
2. Если бот просит войти в Mini App, войди и повтори `/start`.
3. Включи напоминание у привычки, установи время на ближайшую минуту.
4. Дождись сообщения, нажми «✅ Выполнено».
5. Открой сайт и проверь появление отметки.
6. На следующий день напоминание не придёт, если он не выбран в расписании или выполнение уже отмечено.

Важные ограничения: отправка выполняется cron раз в минуту; если cron не запущен,
напоминаний не будет. Служба очередей Redis для 0.4 не требуется.
